# 🚀 PE-SmartFixer：基于 AI 多模态视觉的 Windows PE 离线智能维护工具

本工具彻底颠覆了传统 WinPE 维护需要手动查资料、改脚本的断裂体验。利用大模型多模态视觉（Vision）能力作为智能诊断入口，配合 Go 语言底层硬核掌控力，实现"看图识病，一步到位直接修机"。

> 💡 **致开发者**：本项目核心 Win32 消息循环、异步消息分发、离线注册表 Hive 挂载架构已全部闭环。由于大模型 Token 消耗极高（作者钱包已穿），现将本项目全面开源，交由社区诸位 Go 语言与 Windows 底层神仙共同维护升级！

## ✨ 核心特性

- ⚡ **一步到位**：拒绝写脚本的中间商！AI 视觉看图诊断蓝屏/驱动，Go 底层直接对离线系统执行注册表手术。
- 📦 **零外部依赖**：抛弃臃肿的 Python 环境，纯原生 Win32 API 消息循环调度，编译成品仅数 MB，在精简 PE 环境下稳定运行。
- 🛡️ **多重安全防护机制**：
  - **网络状态预检**：内置网络检测，无网环境下自动降级，主 UI 不卡顿。
  - **环境幂等纯净**：启动时执行清理，修改前自动生成 `.reg` 备份。
  - **异步消息分发**：采用 `PostMessage` 模型，有效规避跨线程野指针与死锁风险。

## 🛠️ 后续社区升级方向

1. **本地离线视觉模型适配**：支持 MiniCPM-V / LLaVA 等轻量模型，实现无网环境下的视觉诊断。
2. **蓝屏 DUMP 文件解析**：离线扫描 `.dmp` 文件，联合视觉进行双重诊断。
3. **PECMD/INI 启动项智能优化**：扩展底层模块，支持对原系统外置加载项进行智能重组。

## 📖 使用说明

### 适用环境

Windows PE（Win7 ～ Win11 内核均可），**需联网**

### 文件清单

```
PE_SmartFixer_v1.0.zip
├── PE_SmartFixer_amd64.exe # 64位主程序
├── PE_SmartFixer_386.exe # 32位主程序（可选）
├── config.json # 配置文件（需用户填 Key）
└── README.txt # 使用说明
```

### 使用方法

1. **准备工作**：将 `PE_SmartFixer_amd64.exe` 和 `config.json` 放入同一目录。编辑 `config.json`，填入你的百炼 API Key：
   ```json
   "api_key": "sk-你的百炼API密钥"
   ```
2. **启动程序**：进入 PE 后，双击 PE_SmartFixer_amd64.exe 即可运行。
3. **诊断故障**：
   - 在文本框中输入故障现象（如"开机蓝屏 0x0000007B"）
   - 点击"📷 选择截图"，可多选蓝屏或报错截图（可选）
   - 点击"🚀 开始诊断"，等待 AI 分析（约 10–60 秒）
4. **确认修复**：AI 返回建议后，根据风险等级选择是否执行：
   - SAFE / WARNING：弹窗询问，点击"是"执行修复
   - CRITICAL：自动熔断，禁止执行，请立即备份数据
5. **完成**：修复完成后按提示重启目标系统。

✅ 修复因关键系统服务被禁用导致的启动失败

✅ 补全缺失或损坏的系统驱动文件（如 iaStorV.sys 等）

**本工具不能做什么：**

❌ 无法修复引导记录损坏（MBR/UEFI 引导丢失）

❌ 无法修改 BIOS/UEFI 固件设置（启动顺序、硬盘模式等）

❌ 无法处理全盘加密（BitLocker）锁定的系统

❌ 无法进行数据恢复（误删文件、格式化等）

❌ 无网络环境下无法使用 AI 诊断功能

### 常见问题

**Q1：提示"无法读取 config.json"？**
A：请确保 config.json 与 exe 在同一目录，且文件格式正确。

**Q2：提示"缺少 api_key"？**
A：请打开 config.json，填入有效的百炼 API Key。

**Q3：AI 请求超时或失败？**
A：请在 PE 中确认网络连接正常（需能访问阿里云 API）。

**Q4：修复后蓝屏依旧怎么办？**
A：程序已自动备份：
- 文件备份：原文件同目录下的 .bak 文件
- 注册表备份：C:\Windows\服务名_Start_backup.reg
- 回滚方法详见修复成功后的弹窗指引。

**Q5：PE 里没有网络怎么办？**
A：⚠️ 本工具依赖云端 AI 模型进行诊断，必须联网才能完成完整的"诊断-修复"闭环。建议使用带网络功能的 PE（如 FirPE、微PE网络版等）。

**Q6：能在正常 Windows 系统下运行吗？**
A：可以启动，但建议在 PE 环境下使用，以避免目标系统文件被锁定导致修复失败。
